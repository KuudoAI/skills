Error 90057
Error message

The [attribute] field contains an invalid value: []. To correct this error, choose from the valid set of values.

Error 90057 causes

Error 90057 occurs when you submit incorrect data in a field that requires a value from a predetermined list of values.

Error 90057 resolution

To resolve error 90057, perform the following steps:

Download the uploaded template and check the attributes affected in the "Feed Processing Summary" tab.
In the template, the affected attributes will be highlighted in orange.
Replace the invalid values provided and choose a valid value from the drop-down list of that attribute.
Resubmit your file to make a successful submission.
If you are uploading multiple products that are unique in nature, you must select all the relevant PTs and then download a template to avoid missing any applicable valid values (As attributes are unique to each PT).
Note: For attributes having drop-down values, do not copy paste any invalid value that is not a part of the drop-down list. This will result in an error. Select the applicable value from the list of drop-downs only.

Error message
A value is required for this column: {0}

Reason for error 99001
The value for a required attribute or column is omitted or missed.

Resolve error 99001
To resolve the error, follow these steps:

Once you provide a value for the "product_type" attribute in column A, all the required attributes are highlighted in red cells. Make sure you cross-check any highlighted cells before you submit your template and ensure that you have provided values for all the highlighted cells.
You can refer to the "Required?" column in the "Data Definitions" tab of the template. This column will indicate whether a particular field (for example: item_name) is required, preferred, or optional.
If you are unable to find the "missing required attribute" mentioned in the error message in your excel template, download the latest template for your product type, fill all the required attributes and submit the file.
Avoid error 99001
To avoid the error, follow these steps:

Use only the latest excel templates when listing your products which are not older than 90 days, as older templates may not be in parity with the latest set of requirements. You can find the version of your template in cell B1 of every template you are attempting to upload.
Avoid pasting over the cells that have drop-downs (for example: product_type) as the values provided for such attributes are validated in the back end and will result in an error if they do not match with Amazon suggested values.
To correct this error, refer to the "valid values" and "data definitions" sheets of your template and update the field to a correct value.

Error 99010
A value is missing from one or more required columns from this group.

This error occurs when there are missing or conflicting values in one of the conditionally required columns. For example, if you are adding a discounted price for a promotion, then the sale start date, end date and sale price are required. If any of these attributes are missing, then this error is called out. The error message reads as follows:

A value is missing from one or more required columns from this group: [Sale Price = null], [Sale Start Date = "2021-05-26"], [Sale End Date = "2022-05-26"].

Note: The sale start date should be less than the sale end date.

In order to resolve this issue, please make sure that all the attributes, of a conditionally required group, are populated with valid values. To prevent this error, check the Data Definition and Valid Values tabs of category-specific flat files before uploading them.

A few instances of conditionally required fields include:

If the Sale Price attribute is filled, then fill in the Sale_start_date and Sale_end_date.
If the Sale Price along with Sale_start_date and Sale_end_date are provided, but your date format is incorrect (i.e. not following either YYYY-MM-DD or DD-MM-YYYY), then you will receive an error.
If the Product_id is filled, then make sure to also fill in Product_id_type.
If Parentage is filled, then make sure to fill in Variation Theme.
