Create a Size Chart for Your Products
Our size charts can help you select the size map as per your preference. Amazon follows a global size chart format and maintains the same for sellers.

To create a size chart for your products, use the size chart self-service tool by going to Catalog > Add size charts

Note: If you are unable to access the size chart self-service tool, contact your primary account manager to enable size chart permissions in User Permissions under Settings. Size charts are only applicable to listings that are Brand registered.
The size chart self-service tool allows you to upload a new, or edit an existing size chart on your own. You can download the size chart template, upload your changes, and preview your size chart before publishing it to your product detail page on Amazon.

If you are a primary account manager or owner and the brand that requires the size chart has Brand Registry, but you do not have access to the size chart self-service tool, follow these steps:


Download the template for the subcategory of your products
Fill in all the details in the template.
Contact Seller Support with the updated size chart template.
Please specify brand name, product subtype and department.
Our team will review the file and create a size chart for you.
